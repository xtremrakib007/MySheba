Common Issues

Make sure you're using the correct phone number. If you forgot your PIN, use the "Forgot PIN" option to reset via OTP. If issues persist, contact support via WhatsApp or Email.
Wallet top-ups are reviewed before crediting. This usually takes a few minutes but can take up to 2 hours during peak times. Ensure you included the correct reference number in your bank transfer.
Dealers typically pick up requests within minutes. If your request has been pending for over 1 hour, please contact support with your request ID.
Phone numbers cannot be changed directly in the app for security reasons. Contact support with proof of identity to request a number update.
